国内、海外、香港本地主机商的退款政策差别很大，理解清楚几种主流模式，你才能在下单前心里有数。

**第一类：3天无理由退款。** 这类商家退款窗口短，往往和"性价比"绑定，靠低价吸引大量用户，自然不敢把退款期拉得太长。野草云就是典型代表——官方服务条款明确写明"虚拟主机/VPS云服务器自订购之日起3天内支持退款"，过期或违反条款一律不退。

**第三类：30天退款。** 这类商家多为欧美大牌，比如Hostinger等就提供30天退款保证，主打"零风险试用"。但搬瓦工这类知名商家近年政策收紧，30天退款还有"账户退款次数限制""总额限制"等隐藏门槛，不是买了就能退。

**第四类：根本不支持退款。** 大量独立服务器、域名、特价促销产品都归入此类。野草云的独立服务器、域名、AWS Lightsail明确不支持退款；很多VPS商家特价产品页购物车里也会标注"特价不退"。

> 简单说：退款窗口越长，你试错的容错率越高，但价格通常也越贵；退款窗口短，往往意味着价格压得更低，需要你下单前做足功课。
